# Privacy and Security Information

### What does it store?

Emojifier stores the following:

- Server IDs for server data (command logging and server-wide blacklists).
- User IDs for user data (command logging, server-wide blacklists, and global bot blacklists).
- Channel IDs for channel data (command logging).
- Webhook IDs and tokens for reposting messages (the text-to-emoji feature).
- Command usage data associated with users and servers, recorded through Emojifier's existing command logging.

### Who can access the data?

The following people can access the data (command logging, server-wide blacklists, and global bot blacklists):

- Bot administrators.
- Bot developers.

[Emojifier Insights](/commands/insights.md) displays statistics based on these existing command usage logs:

- Server views show command usage, active users, leaderboards, and member profiles with server statistics.
- Your personal view shows your recorded command history, favorite commands, activity trends, and activity heatmap across recorded servers.
- When you use the share stats feature, people you share the snapshot with can see the server or personal statistics included in it.

### Why does it store the data?

Emojifier stores server and channel IDs so it can apply settings and log commands in the configured channel.

It stores user IDs so it can detect users on server-wide and global blacklists and associate command usage with users.

Insights analyzes and displays the existing command usage logs to show server statistics, popular commands and conversion styles, rankings, active hours, and personal history and activity trends across recorded servers.

Please join our [support server](https://discord.gg/MTwj6wG) and DM BDL ModMail to request that your stored data, including command usage logs, be removed.
