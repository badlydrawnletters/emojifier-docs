# Emojifier Insights

---

### Description

Emojifier Insights lets you explore how you and your server use Emojifier, right inside Discord. Discover your server's most popular commands, see where you rank, and look back at your own activity across servers.

### Usage

```
/insights
```

Run `/insights` in Discord to open Emojifier Insights. Authorize the app if prompted.

Use it in a server where Emojifier is installed to explore that server's stats, or in a direct message to view your personal history. Choose a view from the sidebar and use the time-range controls to explore your stats.

### Permission Required

Anyone can use this command unless they are globally blacklisted.

> [!TIP]
> Server statistics require Emojifier to be installed in that server. If it is not installed, Insights shows your personal account history instead.

### What You Can Explore

- **Overview:** Your server's command usage, active users, trends, and highlights.
- **Leaderboard:** See the top Emojifier users and select a member to explore their profile and server stats.
- **Commands:** Discover the commands and conversion styles your server uses most.
- **This server:** View your own usage, server rank, favorite command, active hours, and comparison with the server average.
- **All servers:** Explore your personal command history, favorite commands, activity trends, and activity heatmap across recorded servers.

Use **Share stats** to share a snapshot of your server or personal stats. In **Settings & privacy**, you can choose to hide yourself from server leaderboards.
