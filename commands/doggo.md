# Doggo
---
### Description
This command is used to convert text into doggo letter emojis.
### Usage
```
/doggo content: <text>
```
### Permission Required
Anyone can use this command unless they are globally blacklisted.

### Example image
![Doggo command example](../images/convertdoggo.png)

> [!TIP]
> You must have an active [Discord Nitro](https://discord.com/nitro) subscription to use these emojis in other servers.
