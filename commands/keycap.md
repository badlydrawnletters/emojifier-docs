# Keycap
---
### Description
This command is used to convert text into keycap letter emojis.
### Usage
```
/keycap content: <text>
```
### Permission Required
Anyone can use this command unless they are globally blacklisted.

### Example image
![Keycap command example](../images/convertkeycap.png)

> [!TIP]
> You must have an active [Discord Nitro](https://discord.com/nitro) subscription to use these emojis in other servers.
