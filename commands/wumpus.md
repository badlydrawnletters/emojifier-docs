# Wumpus
---
### Description
This command is used to convert text into Wumpus letter emojis.
### Usage
```
/wumpus content: <text>
```
### Permission Required
Anyone can use this command unless they are globally blacklisted.

### Example image
![Wumpus command example](../images/convertwumpus.png)

> [!TIP]
> You must have an active [Discord Nitro](https://discord.com/nitro) subscription to use these emojis in other servers.
