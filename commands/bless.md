# Bless
---
### Description
This command is used to convert text into bless letter emojis.
### Usage
```
/bless content: <text>
```
### Permission Required
Anyone can use this command unless they are globally blacklisted.

### Example image
![Bless command example](../images/convertbless.png)

> [!TIP]
> You must have an active [Discord Nitro](https://discord.com/nitro) subscription to use these emojis in other servers.
