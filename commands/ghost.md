# Ghost
---
### Description
This command is used to convert text into ghost letter emojis.
### Usage
```
/ghost content: <text>
```
### Permission Required
Anyone can use this command unless they are globally blacklisted.

### Example image
![Ghost command example](../images/convertghost.png)

> [!TIP]
> You must have an active [Discord Nitro](https://discord.com/nitro) subscription to use these emojis in other servers.
